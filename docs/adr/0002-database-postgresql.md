# 0002. DB: PostgreSQL

- 상태: 채택
- 날짜: 2026-11-07
- 로드맵 단계: 1
- Issue: #3

## 맥락

회원가입부터 데이터를 저장할 DB가 필요하다. 초기 세팅에서 PostgreSQL을 잠정으로 넣어 두었고, 이 결정으로 확정한다.

## 선택지

### A. PostgreSQL
- 장점: JSONB, 부분 인덱스 등 기능이 풍부하다. `LISTEN/NOTIFY`로 서버 간 메시지 전달을 DB만으로 시도해 볼 수 있다.
- 단점: 국내 실무 사용 비율은 MySQL보다 낮다.

### B. MySQL
- 장점: 국내 실무에서 가장 많이 쓴다. 한국어 자료와 운영 노하우가 많다.
- 단점: 기능이 상대적으로 단순하고, 서버 간 메시지 전달에는 별도 인프라가 필요하다.

## 결정

A. PostgreSQL을 사용한다.

## 이유 (오너 작성)

> DB만으로 서버 간 메시지 전달을 시도해 보고, 더 다양한 기능을 써 보기 위해

## 결과

- 기본 격리 수준은 READ COMMITTED다. 4단계(동시성)에서 갱신 유실(lost update)을 만날 가능성이 크다.
- 7단계에서 `LISTEN/NOTIFY`를 먼저 시도하고, 한계가 보이면 별도 인프라를 검토한다.
