## 맥락

JWT를 발급(서명)하고 검증할 라이브러리를 골라야 한다. 이 선택에 따라 인증 필터를 직접 작성할지, Spring이 제공하는 필터를 쓸지가 갈린다.

## 선택지

### A. jjwt
- 장점: 국내 자료가 가장 많다. 인증 흐름을 코드로 직접 작성한다.
- 단점: 필터, 에러 응답, 필터 체인 내 위치를 직접 정해야 해서 코드가 많다.

### B. Spring Security OAuth2 Resource Server (Nimbus)
- 장점: Spring 공식 방식이다. 설정만 하면 인증 필터와 표준 에러 응답이 자동으로 붙는다.
- 단점: 인증 흐름이 설정 뒤에 가려진다. 이름에 OAuth2가 있어 헷갈리고, 토큰 발급은 따로 구성해야 한다.

### C. java-jwt (Auth0)
- 장점: API가 단순하다.
- 단점: Spring과 함께 쓰는 자료가 적고, 필터는 직접 작성해야 한다.

## 결정

A. jjwt를 사용한다.

## 이유 (오너 작성)

> 인증이 어떤 순서로 일어나는지 코드로 직접 보기 위해서 사용할게

## 결과

- 인증 필터(`OncePerRequestFilter`)를 직접 작성하고, Spring Security 필터 체인에 등록할 위치를 정한다.
- 인증 실패 시 에러 응답 형식을 직접 정한다.
- 인증 필터의 핵심 분기는 `TODO(learn)` 빈칸 대상이다.
