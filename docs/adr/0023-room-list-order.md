# 0023. 내 채팅방 목록 정렬: 생성순으로 시작하고 3단계에서 최근 메시지순으로 바꾼다

- 상태: 채택
- 날짜: 2026-11-10
- 로드맵 단계: 2
- Issue: #7

## 맥락

내 채팅방 목록을 무엇으로 정렬할지 정해야 한다. 정렬 기준은 커서 형태와 인덱스 설계를 좌우한다. 메시지는 3단계에서 생긴다.

## 선택지

### A. 방 생성순 (최신 방이 위)
- 장점: 정렬값(방 id)이 바뀌지 않아 페이지를 넘기는 중에 목록이 흔들리지 않는다. 커서와 인덱스가 가장 단순하다.
- 단점: 메신저 UX와 다르다. 오래된 방에 늦게 들어가면 목록 아래에 묻힌다.

### B. 내가 참여한 순
- 장점: 정렬값(참여 시각)이 바뀌지 않는다. 멤버 테이블 하나에서 정렬할 수 있다.
- 단점: 메신저 UX와 다르다. 참여 시각 컬럼이 필요하다.

### C. 최근 메시지순
- 장점: 실제 메신저와 같다.
- 단점: 3단계 전에는 메시지가 없다. 정렬값이 메시지마다 바뀌어 페이지 사이에 중복이나 누락이 생길 수 있다. 메시지마다 방 행을 UPDATE해야 한다.

## 결정

이번 단계는 A로 구현하고, 3단계(메시지)에서 C로 바꾼다.

## 이유 (오너 작성)

> A안으로 진행하다 메시지 생성 단계부터 C로 전환할게.
> C로 전환하기 전에 커서와 인덱스에 관한 로직을 가장 단순하게 유지할 수 있기 때문이야

## 결과

- 내 채팅방 목록과 공개 방 탐색 목록 모두 방 id 내림차순으로 정렬한다.
- 3단계에서 C로 바꿀 때는 커서 형태와 인덱스를 다시 설계해야 한다. 정렬값이 바뀌는 목록에서 페이지 사이의 중복과 누락을 어떻게 다룰지가 그때의 결정 게이트다.
