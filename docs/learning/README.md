# 학습 기록

로드맵 단계마다 "부숴보기" 실험 결과를 `NN-제목.md`로 남긴다.

## 누가 쓰나

| 칸 | 작성 |
|---|---|
| 예측 | 오너가 실행 전에 자기 말로 쓴다. AI가 대신 쓰지 않는다 |
| 실행, 관찰 | AI가 명령어, 로그, 수치를 바탕으로 초안을 쓴다 |
| 왜 | AI가 초안을 쓰고, 오너가 검토해서 자기 이해와 다르면 고친다 |

## 형식

```markdown
# NN. 실험 제목

## 예측
실행 전에 무슨 일이 일어날 거라고 생각했나.

## 실행
어떻게 재현했나 (명령어, 스크립트).

## 관찰
실제로 무슨 일이 일어났나 (로그, 수치).

## 왜
예측과 달랐다면 그 이유. 어떻게 고쳤나 / 고칠 건가.
```
